# Delivery Platform - Software Testing Project

## 📌 Project Overview

A delivery and transportation platform that supports customers, drivers, and administrators.

The platform includes multiple workflows such as registration, verification, ride requests, driver assignment, payments, subscriptions, offers, notifications, and administrative management.
